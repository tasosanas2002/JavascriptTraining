# **To-Do List Project: Instructions**

## **Objective**  
Complete a To-Do List Application by implementing the following functionalities in a JavaScript file with placeholders.

---

## **Task Object Properties**  
Each task must have:  
- `id` (unique identifier)  
- `title` (string)  
- `description` (string)  
- `priority` (High, Medium, Low)  
- `dueDate` (YYYY-MM-DD)  
- `isComplete` (boolean)  

---

## **Functionality to Implement**  

1. **Add a Task**  
   - Create a task with the given details.  
   - Ensure input validation (e.g., no missing fields).  

2. **View All Tasks**  
   - Display all tasks and their details in the console.  

3. **Mark Task as Complete**  
   - Update the `isComplete` property to `true` by task ID.  

4. **Delete a Task**  
   - Remove a task by its ID.  

5. **Filter Tasks**  
   - By priority (`High`, `Medium`, `Low`).  
   - By due date (`Overdue`, `Upcoming`).  
   - By status (`Completed`, `Incomplete`).  

6. **Edit a Task**  
   - Update a task's title, description, or due date by ID.  

7. **Sort Tasks**  
   - By priority (`High → Low`).  
   - By due date (`Earliest → Latest`).  

8. **Task Summary**  
   - Show total tasks, completed tasks, and incomplete tasks.  

9. **Save and Load Tasks**  
   - Use `localStorage` to persist tasks across page reloads.  

## **Bonus Features (Optional)** 🎯  

1. **DOM Integration**  
   - Create a user interface to display and interact with tasks directly on the webpage.

2. **Search Functionality**  
   - Add a search bar to filter tasks by keywords in their title or description.

3. **Drag-and-Drop Tasks**  
   - Allow users to reorder tasks using drag-and-drop functionality.

4. **Task Highlighting**  
   - Highlight overdue tasks automatically based on the due date.

5. **Dark/Light Theme Toggle**  
   - Add a button to switch between dark and light themes.

6. **Reminders**  
   - Display an alert or visual indicator for tasks due today or overdue.

7. **Task Categories or Tags**  
   - Enable users to group tasks into categories (e.g., Work, Personal) or add custom tags.
